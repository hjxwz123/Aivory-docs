# AI PPT（文多多 Docmee）

Aivory 可以内嵌 Docmee 演示文稿创作台，提供 **AI PPT** 页面。这是一项可选集成：
管理员决定是否对用户开放、配置服务商连接，并可为每份成功生成的演示文稿设置固定积分。

:::info[适用版本]

AI PPT 已包含在 `v2.5.0-beta.2` 及后续测试版本中。请先在测试或预发环境验证，再为生产
用户启用。当前测试版本的说明见[更新日志](../reference/changelog.mdx)。

:::

## 用户会看到什么

只有同时满足以下条件时，侧边栏才显示 **AI PPT**：

1. 已有可用的 Docmee API Key；
2. **启用 AI PPT** 开关处于打开状态。

任一条件缺失时，侧边栏不增加 PPT 入口。`/ppt` 路由仍会保留，旧书签和链接不会变成 404，
但页面会显示不可用状态，不能创建 Docmee token 或开始生成。这样未配置的服务商不会以
半可用功能出现在用户面前。

启用后，任何已登录用户都能使用 AI PPT。当前没有单独的用户组或工作空间权限；无论用户
是否在工作空间中操作，扣费、余额和用量归属发起生成的登录用户。

## 配置集成

进入「**管理后台 → 计费与权益 → 积分与配额**」，找到 **AI PPT（文多多 Docmee）** 区块。

1. 填写 **Docmee API Key** 并保存。以后读取时只显示掩码；把掩码原样提交表示保留原有密钥。
2. 设置 **每份 PPT 所需积分**。填写 `0` 表示免费生成。
3. 选择创作器版本。`v2` 是对话式创作器；只有账户要求旧的分步流程时才选择 `v1`。
4. 除非使用国际版、内部代理或自托管 SDK，否则保持中国大陆服务的默认地址。
5. 打开 **启用 AI PPT**。该开关会立即单独保存；保存成功后，已打开页面会刷新运行时配置，
   用户无需刷新浏览器即可看到侧边栏入口。

| 设置 | 默认值 | 用途 |
| --- | --- | --- |
| 启用 AI PPT | 未显式设置时跟随密钥 | 总开关。显式关闭优先于已保存的 Key。 |
| Docmee API Key | 空 | 服务端用来签发用户范围 iframe token 的密钥。 |
| 每份 PPT 所需积分 | `10` | 每份完成的演示文稿预占并结算的固定积分；`0` 表示免费。 |
| 创作器版本 | `v2` | `v2` 对话式创作器或 `v1` 分步式创作器。 |
| Token 有效期 | `2` 小时 | 请求服务商签发的 token 有效期；`0` 使用服务商默认值。 |
| API 基础地址 | `https://docmee.cn` | 服务端签发 iframe token 的地址。 |
| Domain | 空 | iframe 域名，可填写国际版端点或受控代理。 |
| SDK URL | 固定的 Docmee SDK | 浏览器 SDK 脚本；需要时可替换为受信任内网镜像或自托管副本。 |
| Iframe API 代理地址 | 空 | 浏览器必须经由代理访问 Docmee 时使用的 SDK base URL。 |

API 地址字段可以填写主机名，系统会规范为 HTTPS。URL 非法时整次保存会被拒绝，不会只写入
部分服务商配置。

:::warning[不要让密钥进入浏览器]

不要把 Docmee Key 写入前端构建变量、自定义客户端、共享工作空间说明或截图。Aivory 将
密钥保留在服务端，内嵌 SDK 只会获得短期且绑定当前用户的 token。

:::

## 积分与用量

AI PPT 使用固定单价的三步账本流程：

1. **预占**：上游开始工作前，Aivory 预留设定的积分。余额不足时会在产生服务商成本前
   阻止生成。
2. **结算**：Docmee 上报完成的演示文稿后，Aivory 以其 PPT ID 作为幂等键结算。SDK 重试、
   刷新页面或重复事件不会让同一份 PPT 重复扣费。
3. **释放**：失败或放弃的尝试会释放预占；从未结算的预占会在 30 分钟后自动过期。

只有全局积分体系已开启且**每份 PPT 所需积分**大于零时才会扣费。否则创作台仍可使用且不
扣积分。每次成功且实际扣费的生成都会以 `ppt` 用途记录在「**数据与运营 → 用量与计费**」，
统计和对账能看到真实扣费。

页面不会接受浏览器传入的价格，用户也不能结算或释放其他用户的生成尝试。

## 国际版、自托管与代理部署

默认配置使用中国大陆 Docmee 服务。以下场景只需调整对应服务商字段：

| 场景 | 所需配置 |
| --- | --- |
| Docmee 国际版 | 将 **Domain** 设为 `https://app.xpptx.com`，并填写账户对应的 API 基础地址。 |
| 自托管 SDK | 将 **SDK URL** 指向自行固定的 SDK 副本。除非 API 也需要代理，否则无需修改服务端地址和 Domain。 |
| 受控代理 | 配置 **Domain**、**Iframe API 代理地址** 和服务端 **API 基础地址**，让浏览器 SDK 与服务端 token 请求均经过代理。 |

部署环境还支持 `DOCMEE_API_KEY`、`DOCMEE_API_BASE_URL`、`DOCMEE_DOMAIN`、
`DOCMEE_SDK_URL` 与 `DOCMEE_SDK_BASE_URL`，在对应数据库字段为空时作为启动兜底。数据库
设置优先。常规运维优先使用管理后台；修改兜底变量后需要重启 API 容器。详见[环境变量](../deployment/environment.mdx)。

## 常见问题

| 现象 | 检查项 |
| --- | --- |
| 侧边栏没有 AI PPT | 保存有效 API Key，再打开**启用 AI PPT**。开关关闭时会覆盖已有 Key。 |
| `/ppt` 显示不可用 | 检查 API Key 是否为空或无效，以及启用开关是否打开。 |
| 创作台无法加载 | 检查 SDK URL、浏览器到配置域名或代理的连通性，以及反向代理的内容安全策略。 |
| 用户在生成前被拦截 | 对比其可用积分和**每份 PPT 所需积分**；免费部署可把价格设为 `0`。 |
| 一份 PPT 收到两次服务商事件 | 不要手工再次扣费。Docmee PPT ID 会阻止 Aivory 重复结算。 |
| 用量里没有 AI PPT 记录 | 确认 PPT 收到了成功完成事件，并在「用量与计费」按 `ppt` 用途筛选。 |

对话中返回的生成文件可在统一产物面板打开，使用方式见[对话、文件与产物](../user-guide/conversations-files.mdx)。
