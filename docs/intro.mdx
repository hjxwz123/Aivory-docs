# Aivory 文档

Aivory 是一个可以部署在自己基础设施中的 AI 工作空间。它把多模型对话、文件和知识库、工具调用、团队工作区以及管理策略放在同一个控制面里。

这套文档按任务组织：先让实例可用，再逐步启用更丰富的能力。

## 从哪里开始

- **个人部署**：一台服务器、一个应用容器，使用 SQLite 和内嵌向量，适合个人使用和演示。
- **完整部署**：PostgreSQL、Redis、Qdrant 和沙盒组成的完整栈，适合团队和长期运行。
- **第一次对话**：启动之后，从添加渠道到选择默认模型的最短路径。

## 运行模型

Aivory 的应用容器同时提供网页和 API。模型服务商的 API Key 保存在管理员后台的渠道配置中，不需要写入前端构建变量。

向量后端可以按部署规模选择：

| 部署 | 业务数据 | 向量 | 缓存与队列 |
| --- | --- | --- | --- |
| 个人版 | SQLite | SQLite 内嵌向量 | 进程内 |
| 完整版 | PostgreSQL | Qdrant | Redis |

## 文档约定

命令默认在项目的 <code>deploy/</code> 目录执行。除非特别说明，示例使用 Linux 服务器和 Docker Compose Plugin。公开部署时，请在应用前配置 HTTPS，并且不要把内部数据库服务暴露到公网。
