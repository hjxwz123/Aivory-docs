# 对话与消息表

对话域 9 张表。核心是 `messages` 的**消息 DAG**（`parent_id` 自引用）——分支、重生成、划词子会话都构建在它之上（记法约定见[总览](./overview.mdx)）。

## `projects` — 项目

会话与知识库的容器。共 14 列。

| 列名 | 类型 | 可空 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | TEXT | 否（PK） | — | `p_` + 12 位十六进制 |
| `user_id` | TEXT | 否 | — | FK→`users(id)`，CASCADE |
| `name` | TEXT | 否 | — | 项目名；按 `(user_id, workspace_id)` 作用域唯一（见下） |
| `description` | TEXT | 否 | `''` | 描述 |
| `instructions` | TEXT | 否 | `''` | 项目级系统指令（注入该空间会话的上下文） |
| `accent` | TEXT | 否 | `'violet'` | 主题色标识（前端色板 key） |
| `emoji` | TEXT | 否 | `''` | 图标 emoji |
| `pinned` | INTEGER | 否 | `0` | 置顶 |
| `kb_id` | TEXT | **是** | `NULL` | FK→`knowledge_bases(id)`，`SET NULL`（项目绑定的默认库；删库不删项目） |
| `auto_add_uploads` | INTEGER | 否 | `0` | 项目内上传自动进入其知识库 |
| `created_at` | INTEGER → BIGINT | 否 | `now()` | 创建时间 |
| `updated_at` | INTEGER → BIGINT | 否 | `now()` | 更新时间 |
| `is_public` | INTEGER | 否 | `1` | 工作空间内共享开关：`1` = 共享给成员，`0` = 仅创建者/空间管理员。个人行忽略 |
| `workspace_id` | TEXT | 否 | `''` | ※附加列：软引用 `workspaces.id`；`''` = 个人 |

- **索引**：`idx_projects_user(user_id)`；名字唯一索引在迁移中被替换为三列版 `idx_projects_user_name_unique` ON `(user_id, COALESCE(workspace_id,''), lower(trim(name)))`（`store.go:591-593`）——同一用户可在个人空间与多个工作空间里重名。
- **入向**：`conversations.project_id`（SET NULL）。

| `conversation_id` | TEXT | 否 | — | FK→`conversations(id)`，CASCADE |
| `parent_id` | TEXT | **是** | `NULL` | FK→`messages(id)`，CASCADE——**自引用**边 |
| `role` | TEXT | 否 | — | `user` / `assistant`（应用层只写这两种；无 CHECK） |
| `provider` | TEXT | 否 | `''` | 供应商快照 |
| `model_id` | TEXT | 否 | `''` | 实际服务模型（**无约束快照**） |
| `model_label` | TEXT | 否 | `''` | 模型展示名快照——目录改名/删除后仍可读 |
| `fast` | INTEGER | 否 | `0` | 该轮走了快速模式；用户边界会把 `model_id`/`model_label`/`provider` 掩码 |
| `blocks` | TEXT（JSON） | 否 | `'[]'` | 内容块数组，kind 取值：`text` / `thinking` / `tool_call` / `tool_output` / `citation` / `image` / `document` / `artifact` / `research` / `error`（枚举定义见 `llm/types.go:17`） |

| `attachments` | TEXT（JSON） | 否 | `'[]'` | 文件引用数组（指向 `files.id`） |

| `currency` | TEXT | 否 | `'USD'` | 成本币种 |

| 列名 | 类型 | 可空 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |

| `conversation_id` | TEXT | 否 | — | FK→`conversations(id)`，CASCADE |

| `workspace_id` | TEXT | 否 | `''` | 快照（无 FK） |
| `model_id` | TEXT | 否 | `''` | 快照（无 FK）——删模型不抹质量史 |
| `channel_id` | TEXT | 否 | `''` | 快照（无 FK） |
| `rating` | TEXT | 否 | — | `like` / `dislike`（CHECK） |
| `reasons` | TEXT（JSON）→ **JSONB** | 否 | `'[]'`（PG `'[]'::jsonb`） | 点踩原因多选 |

- **备注**：管理员在「用户反馈」页读取本表做质量分析；`messages.feedback` 旧列只作兼容镜像，不再由新写入路径维护。
