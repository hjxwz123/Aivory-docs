# AI PPT (Docmee)

Aivory can embed the Docmee presentation workbench as an **AI PPT** page. It is
an optional integration: administrators choose whether to expose it, configure
the provider connection, and optionally charge a fixed number of credits for
each completed presentation.

:::info[Availability]

AI PPT is available in `v2.5.0-beta.2` and later test releases. Test it in a
staging environment before enabling it for a production audience. The current
test release is documented in the [changelog](../reference/changelog.mdx).

:::

## What users see

The sidebar shows **AI PPT** only when both conditions are true:

1. a usable Docmee API key is available; and
2. the **Enable AI PPT** switch is on.

When either condition is missing, the sidebar stays unchanged. The `/ppt` route
still resolves for old bookmarks and shared links, but it shows an unavailable
state and cannot create a Docmee token or start a generation. This prevents an
unconfigured provider from appearing as a partially working user feature.

Any signed-in user can use AI PPT after it is enabled. The integration currently
does not add a separate user-group or workspace permission. Generation charges,
balances, and usage attribution belong to the signed-in user who starts the
deck, including when that user is working in a workspace.

## Configure the integration

Open **Admin → Billing & entitlements → Credits and quotas** and find the
**AI PPT (Docmee)** section.

1. Enter the **Docmee API key** and save the section. The key is masked on later
   reads; sending the mask back leaves the stored key unchanged.
2. Set **Credits per presentation**. Enter `0` to keep generations free.
3. Select the creator version. Use `v2` for the conversational creator; choose
   `v1` only when your Docmee account requires the older step-by-step flow.
4. Keep the default China service values unless you use an international
   endpoint, an internal proxy, or a self-hosted SDK.
5. Turn on **Enable AI PPT**. This switch saves immediately. After a successful
   save, connected clients refresh their runtime configuration, so a page reload
   is not required for the sidebar entry to appear.

| Setting | Default | Use it for |
| --- | --- | --- |
| Enable AI PPT | Follows the key until explicitly set | The master availability switch. An explicit off state overrides a stored key. |
| Docmee API key | Empty | Server-side API key used to mint user-scoped iframe tokens. |
| Credits per presentation | `10` | Fixed credits reserved and settled for one completed deck. `0` means free. |
| Creator version | `v2` | `v2` conversational creator or `v1` step-by-step creator. |
| Token lifetime | `2` hours | Requested upstream token lifetime. `0` leaves the provider default. |
| API base URL | `https://docmee.cn` | Server-side endpoint that mints the iframe token. |
| Domain | Empty | Iframe domain. Set the international endpoint or your controlled proxy here. |
| SDK URL | Pinned Docmee SDK | Browser SDK script. Set a trusted internal mirror or self-hosted copy when needed. |
| Iframe API proxy base | Empty | SDK base URL when the browser must reach Docmee through your proxy. |

The API URL fields accept a hostname and normalize it to HTTPS. Invalid URLs
reject the save rather than applying a partial provider configuration.

:::warning[Keep the key out of the browser]

Do not place a Docmee key in a frontend build variable, a custom client, a
shared workspace note, or a screenshot. Aivory keeps the key server-side and
issues only a short-lived, user-scoped token to the embedded SDK.

:::

## Credits and usage

AI PPT uses a fixed-price, three-stage ledger flow:

1. **Reserve**: before the upstream starts work, Aivory reserves the configured
   number of credits. An insufficient balance blocks the generation before it
   can incur provider cost.
2. **Settle**: when Docmee reports the completed deck, its presentation ID is
   used as the idempotency key. SDK retries, page reloads, and repeated provider
   events cannot debit the same deck twice.
3. **Release**: a failed or abandoned attempt releases its hold. Holds that
   never settle expire automatically after 30 minutes.

Charging is active only when the global credit system is on and **Credits per
presentation** is greater than zero. Otherwise the creator remains available
and does not deduct credits. Every settled, charged deck is recorded under the
`ppt` purpose in **Data & operations → Usage & billing**, so usage statistics
and billing reviews reflect the actual debit.

The page never accepts a price from the browser. A user cannot settle or release
another user's generation attempt.

## International, self-hosted, and proxy deployments

The default setup targets the China Docmee service. For another deployment
shape, change only the provider fields that match it:

| Scenario | Required configuration |
| --- | --- |
| International Docmee | Set **Domain** to `https://app.xpptx.com` and set the API base URL supplied for the account. |
| Self-hosted SDK | Set **SDK URL** to your pinned SDK copy. Keep the server API base and domain unchanged unless they also need a proxy. |
| Controlled proxy | Set **Domain**, **Iframe API proxy base**, and the server **API base URL** so both the browser SDK and server token request use your proxy. |

The deployment also supports `DOCMEE_API_KEY`, `DOCMEE_API_BASE_URL`,
`DOCMEE_DOMAIN`, `DOCMEE_SDK_URL`, and `DOCMEE_SDK_BASE_URL` as startup
fallbacks when the matching database setting is blank. Database settings take
precedence. Prefer the admin UI for normal operations; changing a fallback
variable requires restarting the API container. See [Environment variables](../deployment/environment.mdx).

## Troubleshooting

| Symptom | Check |
| --- | --- |
| AI PPT is absent from the sidebar | Save a valid API key, then turn on **Enable AI PPT**. If the switch is off, it overrides the key. |
| `/ppt` says unavailable | Check whether the API key is blank or invalid and whether the enable switch is on. |
| The creator fails to load | Verify the SDK URL, browser access to the configured domain or proxy, and any content-security policy on your reverse proxy. |
| A user is blocked before generation | Compare their available balance with **Credits per presentation**, or set the price to `0` for a free deployment. |
| A completed deck appears twice in provider events | Do not manually debit it. The Docmee presentation ID prevents a duplicate Aivory charge. |
| Usage does not show an AI PPT charge | Confirm the deck reached a successful completed event and filter Usage & billing by the `ppt` purpose. |

Generated files returned in chat can be opened in the shared Artifact Panel; see
[Conversations, files, and artifacts](../user-guide/conversations-files.mdx).
