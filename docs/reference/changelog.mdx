# 更新日志

本页记录会影响部署、管理员配置和日常使用的变化。应用镜像的精确版本以 GitHub Releases 和镜像标签为准。

## 2026-08

### 个人版部署

- 增加使用 SQLite 业务库、SQLite 内嵌向量和进程内缓存的个人版 Compose 配置。
- 个人版默认只启动应用容器；沙盒改为可选 `sandbox` profile。
- 完整版继续使用 PostgreSQL、Redis、Qdrant 和沙盒，原有环境变量和数据卷保持兼容。

### 管理员配置

- 渠道添加页支持从服务商模型接口自动导入模型。
- 不再为任何模型默认添加服务商托管工具，工具需要管理员显式启用。
- 首次进入管理员页面提供可跳过、可重看的漫游式配置引导，并根据个人版或完整版显示对应步骤。
- 没有本地或外部沙盒时，工具页会提示先配置沙盒并关闭 Python 解释器开关。

### 对话体验

- 历史对话菜单增加分享模态框，可创建和撤销只读公开快照。
- 渲染后的数学公式支持点击复制 LaTeX 文本。
- 对话抽屉标题、引用文字和主对话标题统一字体，降低不必要的线框和分割线。

### 发布与架构

- 应用、沙盒 sidecar 和沙盒运行时镜像支持 `linux/amd64` 与 `linux/arm64`。
- x86_64 旧部署可以继续使用原有卷和更新命令；跨架构迁移前需要先备份并恢复数据。

## 升级提示

升级前固定 `IMAGE_TAG`，备份个人版的整个 `DATA_DIR`，或同时备份完整版的数据库、Redis、Qdrant 和文件目录。升级后检查管理员后台的系统状态和模型配置，再恢复对外流量。

## 发布策略

当前说明跟随主仓库的稳定分支发布。需要维护长期支持版本时，先为应用和说明建立对应 release，并维护对应版本的内容。
