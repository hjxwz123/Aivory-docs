# 内部提示词总览

本模块记录 Aivory 2.4.6 随源码发布的全部固定模型提示词和提示词包装结构，包括主聊天系统提示词、内部任务模型调用、检索与记忆任务、图片与深度研究流程、Verify、工具循环指令，以及内置文档生成技能。

源码是最终准则。补全本目录时，所覆盖的提示词文件在 `v2.4.6` 标签与应用当前 `main` 分支之间没有变化。

## 公开边界

本目录公开固定源码字符串和准确拼接规则，但**不会**公开以下实例或用户数据：

- 管理员配置的模型系统提示词、审核分类和自定义压缩指令；
- 人格、昵称、自定义指令、项目指令、管理员或用户的技能正文及记忆；
- 文档名称、上传文件内容、选中片段、用户消息、助手回答、搜索结果和工具输出；
- API Key、渠道配置、数据库内容及真实请求中的服务商载荷。

对于这些值，文档只展示占位符、边界标签、插入顺序和信任级别。`<USER_MESSAGE>` 等占位符表示运行时数据，并不是实际发送的固定文字。

## 如何阅读模板

每页会区分四类模型输入：

1. **System prompt：** 应用发送的最高优先级固定指令。
2. **Request template：** 服务端为内部任务构建的用户层请求正文。
3. **动态数据：** 插入模板的运行时内容，文档会明确其信任边界。
4. **输出契约与回退：** 接受的输出结构、规范化规则，以及模型失败后的处理方式。

有些提示词是按条件拼接的，并不存在单个常量。此时文档会列出每个固定片段，以及 [`composeSystemPrompt`](https://github.com/hjxwz123/Aivory/blob/v2.4.6/server/internal/llm/orchestrator_context.go) 使用的准确顺序。主聊天固定文字在 [`prompt_l10n.go`](https://github.com/hjxwz123/Aivory/blob/v2.4.6/server/internal/llm/prompt_l10n.go) 中支持英文、简体中文、繁体中文、日文和法文；英文站列出英文原文，中文站列出实际使用的简体中文原文。

## 变更规则

提示词变化属于行为变化。后续版本修改固定契约时，应同时更新本模块、覆盖矩阵和源码版本链接。任何私有运行时数据都不应复制到公开文档、Issue、截图或 Release Notes 中。
