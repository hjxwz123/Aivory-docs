# 第一次对话

实例启动后，完成下面三步就可以开始聊天。

## 1. 添加渠道

在管理员后台打开“渠道”，选择服务商类型和接口格式，填写 Base URL 与 API Key。OpenAI 兼容渠道通常使用以 <code>/v1</code> 结尾的地址。

渠道只保存上游连接信息，不会自动让所有模型可用。

## 2. 添加模型

进入“模型”，创建一个聊天模型，或者打开渠道的“自动添加渠道支持的模型”功能，从服务商的模型接口导入列表。

同一个模型 ID 可以属于不同渠道。例如两个渠道都支持 <code>gpt-5</code> 时，可以分别添加两个模型记录；运行时会根据各自的渠道配置区分它们。

## 3. 选择默认模型

在“设置 → 模型策略”中选择一个已启用的聊天模型作为默认模型，然后返回首页新建对话。

## 常见的下一步

- 需要知识库时，添加 embedding 模型并创建知识库。
- 需要联网回答时，配置搜索服务商。
- 需要 Python 或文件工具时，确认沙盒地址可访问。
- 需要团队协作时，创建工作区并设置成员权限。
