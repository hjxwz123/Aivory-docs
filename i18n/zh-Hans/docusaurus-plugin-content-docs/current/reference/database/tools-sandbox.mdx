# 能力与集成表

能力目录域 7 张表：管理员目录（`skills`/`prompts`/`mcp_servers`/`image_styles`）+ 用户私有副本（`user_skills`/`user_prompts`/`user_mcp_servers`）。**沙箱会话状态不在数据库里**——sidecar 内存 + `/workspace` 按 conversation id 归档到对象存储（见[沙箱概览](../../sandbox/overview.mdx)）（记法约定见[总览](./overview.mdx)）。

## `skills` — 管理员技能目录

Agent Skill = 指令 + 资源包。共 10 列。

| 列名 | 类型 | 可空 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | TEXT | 否（PK） | — | `sk_` + 12 位十六进制 |
| `name` | TEXT | 否 | — | 技能名；`lower(trim(name))` 唯一（重名在迁移中合并 `dedupeSkillNames`） |
| `description` | TEXT | 否 | — | **模型可见**的触发元数据（决定何时启用该技能） |
| `display_description` | TEXT | 否 | `''` | 仅目录展示的文案，与触发元数据分离 |
| `icon` | TEXT | 否 | `''` | 图标 |
| `instructions` | TEXT | 否 | — | 技能正文（注入模型上下文） |
| `assets` | TEXT（JSON） | 否 | `'[]'` | 可打包资源清单（管理员专属——**用户副本没有这列**，见下） |
| `enabled` | INTEGER | 否 | `1` | 是否上架 |
| `sort_order` | INTEGER | 否 | `0` | 排序 |
| `updated_at` | INTEGER → BIGINT | 否 | `now()` | 更新时间 |

- **入向**：`model_skills.skill_id`（CASCADE）、`user_skills.source_skill_id`（SET NULL）。

## `user_skills` — 用户私有技能

管理员技能的私有副本或用户自建。共 10 列。**故意没有 `assets`/存储列**——私人技能只有指令，**永远不能**向沙箱投放文件（安全边界）。

| 列名 | 类型 | 可空 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | TEXT | 否（PK） | — | `usk_` + 12 位十六进制 |
| `user_id` | TEXT | 否 | — | FK→`users(id)`，CASCADE |
| `workspace_id` | TEXT | 否 | `''` | 软引用；`''` = 个人库，非空 = 该空间共享 |
| `name` | TEXT | 否 | — | 名字（唯一性按作用域拆成两组部分唯一索引，见下） |
| `description` | TEXT | 否 | — | 触发描述 |
| `icon` | TEXT | 否 | `''` | 图标 |
| `instructions` | TEXT | 否 | — | 正文 |
| `source_skill_id` | TEXT | **是** | `NULL` | FK→`skills(id)`，`SET NULL`——溯源"从目录复制" |
| `created_at` | INTEGER → BIGINT | 否 | `now()` | 创建时间 |
| `updated_at` | INTEGER → BIGINT | 否 | `now()` | 更新时间 |

- **索引**（均在迁移中创建，`store.go:598-607`）：`idx_user_skills_user(user_id, updated_at DESC)`、`idx_user_skills_workspace(workspace_id, updated_at DESC)`；名字唯一按作用域：个人行 `(user_id, lower(trim(name))) WHERE workspace_id=''`，空间行 `(workspace_id, lower(trim(name))) WHERE workspace_id<>''`；另有两个防目录重复复制的 source 唯一索引（同样按作用域拆）。
